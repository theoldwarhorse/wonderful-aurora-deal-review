# The brief

The original assignment from Wonderful. The task and time expectation below are reproduced verbatim.

## The task

Aurora Bank uses an AI agent to extract key details from corporate and investment banking loan agreements. Each deal includes several PDFs: the original agreement, schedules, amendments, and supporting documents.

Before the extracted details are captured in a downstream system, a deal manager must review and approve them.

Build the UI that helps the deal manager perform that review.

The deliverable should be a mock up or prototype you might show to deal managers to get feedback on the UI and UX. You may use AI and any tools or frameworks you prefer. Submit a runnable application and a short note explaining your assumptions, key decisions, and what you would improve with more time

## Time expectation

The task is intentionally a bit open ended and you'll have to make assumptions and come up with sample data yourself. The expectation is that you only spend a couple of hours on it, leveraging agentic coding tools.
